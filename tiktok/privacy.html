AIMP - Privacy Policy

AIMP is a personal application that runs only on its owner's computer.

What it receives from TikTok: when the owner connects their TikTok account, TikTok gives AIMP an access token, a refresh token and the account's open ID and display name. AIMP keeps them only in a file on the owner's own computer, to upload the owner's videos to the owner's account. They are never sent anywhere else, never shared and never sold.

What it sends to TikTok: only the videos the owner chooses to upload, with their title.

This website (the sign-in return page) stores nothing; it only passes TikTok's sign-in code to the AIMP app on the owner's own computer.

The owner can disconnect at any time in TikTok's settings (Security → Manage app permissions), and by deleting the token file on their computer.
